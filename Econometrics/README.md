# ECON303400 Introduction to Econometrics II
Offered by [Department of Economics](https://econ.site.nthu.edu.tw/)

**Grade:** Withdrawn (Spring 2025)

**Textbook:** [Introductory Econometrics: A Modern Approach](https://www.amazon.com/Introductory-Econometrics-Modern-Approach-MindTap/dp/1337558869)

## About
In this course, students collaberate in groups to write an essay on a self-selected topic. Our group investigated the **relationship between the baseball team performance and star plyers** in [CPBL](https://www.cpbl.com.tw/). I was responsible for **collecting data from the official website**.

## Methods
**Programming Language:** Python
**Library:** selenium, BeautifulSoup, pandas

I manipulated the website by selenium, crawled data by BeautifulSoup, and outputed csv file by pandas.
